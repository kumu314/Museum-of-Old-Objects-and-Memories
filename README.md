# 拾物馆

以旧物、故事和真实 3D 收藏柜为核心的纪念展产品。最终目标采用方案 B：用户自己上传照片与讲述，生成 3D 模型和展签草稿，预览确认后发布分享。账号与个人制作界面已接入，完整自助建模流程尚未实现或验收。

当前工程的应用、三维预览、测试和文档已统一到 `heikesong`。已支持自助注册、按账号隔离资源、每账号一座有效展馆、分页工作台及 `/museum` 本人草稿预览。工作台可处理图片与音频、整理故事、确认展品、发布版本、复制参观链接、换链或停止分享；`/share/[token]` 要求登录并持有效链接，展示发布快照、三维展柜、实拍、展签和主动播放的原声。

混元单图与四视图照片准备可保存；生产方向为官方云 API，演示方向为 concept 网页反代，两套服务端适配器已有实现，尚未接入业务任务。动态 GLB 加载与独立制作预览已实现，持久化生成任务、生成模型入库及模型快照仍待完成。当前进度见 [实施状态](docs/IMPLEMENTATION_STATUS.md)，最新验证及未执行项见 [验收清单第 8 节](docs/11-验收清单.md#8-代码审查修复复验2026-10-24)；完整首版与生产部署尚未验收。

## 快速启动

使用项目固定的 Node.js 26.12.0、pnpm 12.14.0，准备 Docker Compose、`ffmpeg` 与 `ffprobe`：

```sh
pnpm install --frozen-lockfile
pnpm db:local
pnpm db:migrate
pnpm db:migrate:test
pnpm dev
```

应用：`http://127.0.0.1:17682/`。三维原型另运行 `pnpm dev:scene`，地址为 `http://127.0.0.1:17681/`。

配置、账号注册与预置、检查命令、隔离 HTTP 回归及部署限制统一见 [运行说明](docs/运行说明.md)。真实配置、凭据、数据库和上传素材不能提交；已有 `.env.local` 不会被初始化脚本覆盖。
