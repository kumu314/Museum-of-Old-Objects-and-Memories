# 拾物馆

以旧物、故事和真实 3D 收藏柜为核心的纪念展产品。最终目标采用方案 B：用户自己上传照片与讲述，生成 3D 模型和展签草稿，预览确认后发布分享。2026年10月24日更新规划，尚不代表自动建模或用户自助流程已经实现。

当前工程的应用、三维预览、测试和文档已统一到 `heikesong`。团队登录、工作台、素材处理、发布与分享 API，以及 `/share/[token]` 正式参观页已接入。工作台可发布已确认版本、生成和复制参观链接、换链或停止分享；参观页显示发布快照、三维展柜、实拍、展签和主动播放的原声。成员 A 的动态模型加载与制作预览已实现，个人归属隔离、三维生成任务及模型资产持久化仍待实现。完整首版与生产部署尚未验收，当前进度见 [实施状态](docs/IMPLEMENTATION_STATUS.md)。

## 快速启动

使用项目固定的 Node.js 26.12.0、pnpm 12.14.0，准备 Docker Compose、`ffmpeg` 与 `ffprobe`：

```sh
pnpm install --frozen-lockfile
pnpm db:local
pnpm db:migrate
pnpm db:migrate:test
pnpm dev
```

应用：`http://127.0.0.1:17682/`。三维原型另运行 `pnpm dev:scene`，地址为 `http://127.0.0.1:17681/`。

配置、团队账号、检查命令、隔离 HTTP 回归及部署限制统一见 [运行说明](docs/运行说明.md)。真实配置、凭据、数据库和上传素材不能提交；已有 `.env.local` 不会被初始化脚本覆盖。
