## 选题：记忆博物馆

面向个人和家庭的旧物纪念展制服务，用 3D 收藏柜保存物品及其背后的故事。

- **闭环**：一个具体的人提出纪念需求 → 提供旧物和故事 → AI 整理、制作 → 对方看到完整展柜并打开参观
- **产品内容**：收藏旧物、记录物品背后的故事
- **呈现方式**：有分格、灯光、旋转检视的 3D 收藏柜
- **参赛方向**：OPC 产品创作

选题怎么定出来的：`docs/03` – `docs/06` 四份过程记录（候选 → 头脑风暴 → 三方向评估 → 评分准则重排）。

## 30 秒上手

```bash
# 1. 装提交钩子（克隆后跑一次，只需一次）
bash scripts/install-hooks.sh

# 2. 全仓库噪声扫描（空壳文件 / 调试残留 / 大文件 / 敏感文件）
node scripts/scan-noise.mjs
```

只要 Node ≥ 18，不需要 `npm install`。

2. **数据**：演示必须用真实产出。模拟数据可以跑链路，但不能当战果讲。
3. **提交**：截止前 2 小时完成提交，留缓冲。代码 + 演示材料 + 录屏缺一不可。
