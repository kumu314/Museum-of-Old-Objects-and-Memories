# 方案 B：A 的动态模型与制作预览

本模块提供三维渲染输入和动态模型预览组件，不定义 HTTP、数据库或模型生成任务契约。工作台及本人展馆已通过 `CabinetPreview` 接入实时展柜；本文的 `ModelPreview` 仍用于独立样例，待业务生成结果接入。C 维护共享 schema、模型素材归属和发布快照，D 提供服务端生成、处理并验证过的模型，B 接入候选模型预览与采纳。独立样例使用明确标识的已有资产；业务展柜已接入私有生成模型，当前工作区另接入发布快照模型。真实相机样例的桌面范围见验收清单，不代表所有目标设备已验收。

生成适配器已区分[生产用官方云 API](../../server/integrations/hunyuan3d/README.md) 与[演示用 concept 网页反代](../../server/integrations/hunyuan3d-proxy/README.md)，均已接入单图持久化任务、私有模型入库与入柜；发布快照模型由当前工作区迁移 0017 接入（尚未提交）。concept 的历史文生白模不代表照片生成与纹理成品可用。最新工程验证及未执行项见 [验收清单](../../../docs/11-验收清单.md) 的 2026-10-25 工作区增量。

## C / D 交给 A 的内容

- GLB 2.0，单个 scene，几何缓冲和图片全部内嵌；当前不配置 Draco / Meshopt / KTX2 解码器。D 在入库前完成完整格式与文件校验、图片解码预算、几何简化和可加载验证。
- `GlbModelSource`：`{ assetId: string, version: string, url: string }`。这是渲染输入，`version` 为非空的模型修订标记，不代替业务接口的乐观锁版本。每次重新生成使用新的素材记录；版本或地址变化会取消旧请求。
- `url` 由应用根据已授权的素材 ID 解析为本站读取接口；允许相对路径，禁止第三方地址、重定向、文件地址和内嵌凭据。生成服务返回的文件先由后端下载、校验并持久化，不将服务商链接或真实模型放进 `public`。
- 制作页读取检查会话与所有者；参观页读取检查有效会话、当前 token、分享状态、当前快照与模型素材成员关系。素材响应禁止缓存。调用方负责这些服务端条件，渲染器不直接调用数据库或生成服务。
- 当前查看器预算（`src/features/cabinet/glb-model.ts` 的 `modelBudget`）：64 MiB、600,000 三角面、单张贴图每轴最多 4096 像素、总贴图最多 64,000,000 像素。6400 万像素预算为 2026-10-25 经授权的桌面真实样例调整，不代表手机性能通过。客户端检查是第二道限制，不能替代服务端在解码前检查；这些上限尚未通过真实手机定标。

## B 如何嵌入

`ModelPreview` 位于 `model-preview.tsx`，是客户端组件。调用方提供：

| 参数 | 职责 |
| --- | --- |
| `source`、`label` | 已授权模型的读取信息与旧物名称 |
| `value`、`onChange` | 陈列设置的唯一事实来源；组件不自行保存服务器或浏览器副本 |
| `fallback` | React 内容，提供实拍与故事入口，加载失败或 WebGL 中断后继续可用 |
| `onApply(selection)`（可选） | 显式采用时返回 `{ assetId, version, placement }`；B/C 使用当前展品版本提交，并处理保存失败和 409，组件不自动确认故事或发布 |
| `applying`（可选） | 保存中禁用调整和采用；失败后由调用方保留参数并显示业务错误 |

`ModelPlacement` 为 `{ rotation: [x, y, z], size }`：XYZ 欧拉角，单位度，范围 -180 至 180；`size` 为 0.25 至 1，默认 0.75，相对于旋转后包围盒的最大安全适配比例，不表示测量过的实物尺寸。计算保留模型自身节点变换，在柜格内居中、落地且各轴不超过可用空间的 90%。检视拖动与缩放只改变临时观察状态，不写入陈列设置。

模型替换时 Canvas 和查看器控制器保留，旧请求取消、旧模型资源释放；尚未结束的解析返回后也会检查取消状态并释放结果。`destroy()` 取消本次请求、动画、指针捕获、订阅和观察器，释放所属几何、材质、纹理与 ImageBitmap，并通过 `WEBGL_lose_context` 关闭所属原生上下文。销毁后调用方移除该 Canvas，下次挂载创建新 Canvas。调整陈列不会重新下载模型或重建 Canvas。工作台 `CabinetPreview` 按实际模型来源及成员保持场景实例；刷新资料、改名和同页格位调整通过 `setArrangement` 更新，不重新下载或解析模型。模型来源、成员或页码变化仍按生命周期取消旧请求并重建。

检视支持单指拖动旋转、双指按距离缩放、滚轮、方向键与加减键，双击画布复位视角。正式参观页和独立展柜预览用旋转弧线与放大镜提示操作，不再展示文字缩放与重置按钮；制作预览仍提供至少 44px 高的显式放大、缩小按钮。多指操作不会同时旋转或误触选择，指针取消和卸载会释放捕获。缩放范围为初始观察的 0.75–1.45 倍，与陈列大小分开。

底层 `mountCabinetStage` 新增输入：

```ts
{ id, slot, plaqueText, modelKey: 'glb', source, placement }
```

并新增 `setModelSource(id, source)`、`setModelPlacement(id, placement)`、`zoomBy(factor)`，可选回调 `onModelStats(id, stats)`、`onAssetError(id, message)`。`getDiagnostics()` 只读返回表面状态、临时观察值、待执行帧/请求、原生上下文是否丢失及渲染器资源计数，用于检查台，不作为业务状态来源。原有清单模型、实拍薄片和四态检视继续使用；`modelManifest` 只登记演示资产，不登记每个用户生成的资产。

## 独立样例与联调边界

运行 `pnpm dev:scene`，打开 `http://127.0.0.1:17681/model-preview.html`。样例支持切换模型、替换版本、模拟失效、调整与采用参数；“采用”只显示本页结果，刷新恢复初始值。检查台为 `/qa.html?preview=model`，可检查 390×844、减少动态效果、静止帧和 WebGL 中断恢复。加上 `&webgl=blocked` 可模拟首次初始化失败，点击检查台“允许 WebGL 初始化”后，再点击组件“重试三维展示”验证恢复；该模拟仅影响当前 iframe。

`/model-lab.html` 提供实际 GLB 边界、延迟旧响应、加载中退出、30 次切换、24 次挂载卸载、合成双指及首次 WebGL 失败重试检查。所有故障注入和监听器/观察器计数均局限于这个独立页面。夹具来源与再生成命令见 [fixtures/README](../cabinet/demo/fixtures/README.md)，实际结果统一见 [验收清单](../../../docs/11-验收清单.md)。

资源记录保留 Three.js 原始计数。其内部 transmission 贴图在 `dispose()` 后仍可能显示 2，不应手动归零；卸载同时核对原生上下文已丢失、几何与程序已释放、请求/帧停止以及监听器/观察器回到基线。渲染 CPU 记录是本机提交耗时，不能当作 GPU 时长或手机性能结论。

`pnpm build:scene` 构建完整展柜、模型预览、稳定性检查台和视觉检查台四份 HTML。资产保留文件 URL，避免小 GLB 被内嵌为数据地址而违背同源读取约定。复用的 React 组件含 Next.js 的 `use client` 声明，Vite 会提示该指令在普通浏览器打包中不保留；不影响这个纯客户端入口。Next.js 接入仍保留客户端边界。

当前工作区的公共 schema 已包含可选的 `generatedModelAssetId`，发布冻结模型成员（迁移 0017），`public-stage-items.ts` 已映射到授权分享模型接口；旧快照缺省该字段时继续使用原展示。该增量尚未提交，接口和映射接入不等于完整体验验收；形状、纹理、方向、文件预算及实际手机仍须按真实样例与目标设备分别验证。
