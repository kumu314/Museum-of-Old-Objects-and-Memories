# Walnut Veneer 原型材质来源

- 作者：Jenelle van Heerden
- 官方资产：https://polyhaven.com/a/walnut_veneer
- 文件清单：https://api.polyhaven.com/files/walnut_veneer
- 许可：CC0；https://polyhaven.com/license
- 文件：官方 1K JPG diffuse / OpenGL normal / roughness，未采用官网预览渲染图。
- 当前渲染使用 diffuse、roughness 和 OpenGL normal；法线强度 0.22，非金属、低清漆强度。按来源 1.8 m 的纹理宽度映射到约 6 个场景单位，各板材分别选择方向与 UV 偏移，避免相同图案铺满六格。
- 用途：原创柜体几何的表面材质，不代表真实客户家具的实拍。
