# 历史参考图薄片来源

本文件保留 2026-10-23 薄片原型的来源及实现记录。当前 `model-manifest.ts` 已改为加载独立的 `cassette.glb`、`ticket.glb`；运行时不再裁切 `reference-overview.png` 或调用旧薄片生成器。当前模型、程序化重绘纹理和尺寸见 [MODELS_SOURCE.md](MODELS_SOURCE.md)。下面的裁区、2 mm 厚度及 60% 柜格占宽仅描述历史版本，不是当前模型参数。

- 来源：用户在本次对话中提供并授权作为本项目原型参考的展柜效果图。
- 保存方式：原图原样复制为 `reference-overview.png`，尺寸 1672 × 941；未编辑或重新编码原文件，不产生裁切后的图片文件。
- 原图与副本的 SHA-256 均为 `8f5a50b8def6f943d9bcb9438b3597d9069c43774700e1a25b451ff34d0e482e`。
- 表现方式：**参考图正面贴图薄片，侧背面示意**。不是物体的精确三维复原；图中的文字、年代与票面均来自参考图，不作为真实藏品或已确认故事的事实来源。
- 当时的运行时裁切：磁带 `(x: 718, y: 269, width: 240, height: 146)`；车票 `(x: 701, y: 579, width: 272, height: 146)`。坐标原点是原图左上角。
- `createImageBitmap` 在模型加载时从原图选取正面区域。磁带正面、浅浮层卷轴与纸签沿用相同连续 UV；侧面为烟灰色、背面为深棕色，并叠加程序化划痕薄罩。车票侧背面为泛黄纸色，保留 2mm 厚度，叠加纸纤维凹凸和极轻微折角受光。
- 两件均后倾 8°，增加深色微型底托与后支撑；侧背面与展托均为示意。包含全部节点变换的模型按完整包围盒恢复到底部中心原点，陈列宽度仍为柜格的 60%。
