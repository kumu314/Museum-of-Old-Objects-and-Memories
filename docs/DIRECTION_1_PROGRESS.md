# 方向一实现与验证记录

日期：2026-10-24。代码基线：`3a6010d`；本地分支：`codex/direction1-contract-proposal`。本记录只描述已实现和实际运行的内容，不表示已提交、合入、部署或完成方向一全部目标。

## 已确认的产品与协作决定

- 新馆默认私密；首轮只有 DEMO，真实公开互动不开放。
- 发布快照与开放访问分开；新馆发布后仍私密。旧有效分享只迁移为持链接访问，不自动公开。
- 关注账号、收藏展馆；关注列表仅本人可见；所有访客都不看收藏者名单，只看总数。
- 手动标签首版在馆级，随发布快照生效。
- 禁评只禁止本馆留言，仍可参观有权访问的馆；首版留言不支持编辑。
- 禁止自关注、自收藏；作者删除根留言保留回复和删除占位，馆主隐藏根留言隐藏整条线程。
- 自传导出 Markdown 和 JSON；明确确认删除后删除在线资料及公开许可。备份期限由部署负责人确认，未定之前不开放真实资料。
- 本对话是方向一共享 schema、权限、迁移和 API 的唯一作者；方向二只消费契约。未获提交、推送、PR、合并、付费调用或部署授权。

剩余产品选择仍见[契约提案](DIRECTION_1_CONTRACT_PROPOSAL.md)，包括访问撤销后的收藏计数保留规则、真实深访额度及价格、真实模型/费用预算和供应商数据处理条件。不将演示额度解释为真实赠送次数。
