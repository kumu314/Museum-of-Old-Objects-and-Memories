6. 正式参观页的无 WebGL、模型失败和上下文丢失状态保留故事/照片/重试入口。卸载调用 destroy；切换展品停止并重置旧音频，默认不播放。先保存同视口总览基准，再验证检视、返回、窗口改变、键盘及故障恢复。

每个关键阶段完成后补充：实现者（用户本人负责、编码助手协助）、复核类型“单人自查”、检查的实际 diff、验证命令与结果、未解决项及对应 AC 编号。没有运行的项目保持“未执行”；缺配置/设备标“环境阻塞”；失败保留失败结果直到修复后有新的通过证据。此初始盘点不构成权限、发布、迁移或生产部署的自查通过结论。
