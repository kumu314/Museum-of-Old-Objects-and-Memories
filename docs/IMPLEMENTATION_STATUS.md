- 固定工具链、公共 schema、PostgreSQL、迁移、类型与 lint、测试和生产构建入口已建立。
- 会话、工作台、图片音频处理、版本冲突、确认、事务快照与分享 API 已实现；服务端支持用户名+密码自助注册并按账号隔离展馆、展品与素材，旧团队账号也只访问自己创建的馆。分享数据及素材 API 要求有效登录与当前有效 token。
