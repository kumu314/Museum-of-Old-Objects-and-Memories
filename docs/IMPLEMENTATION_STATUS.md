## B 工作台与参观界面（本分支）

- 工作台采用深色暖金与木质六格展柜，桌面三栏、手机“素材 / 故事 / 确认”页签；专用样式与首页、登录页分离。首页和登录页由另一位作者接入，本次只对齐其 HTML 设计稿的配色、字体与按钮。
- 名称、共同回忆、照片与可选原声接回已有接口；原始讲述、录音整理、AI 草稿及人工展签分别呈现。保存、采纳、确认与发布仍是独立操作，版本冲突保留本地输入。
- 复用 A 的场景和四态检视，选择格位只切换编辑对象，同页放大检视与返回复用 Canvas。照片仅作明确标识的平面展示；内置 GLB 明确标注演示来源，不冒充照片生成。
- 新增 `/share/[token]`，只读取公开快照与当前分享素材；页面、数据和素材均要求有效用户会话，其他登录用户凭当前链接可参观但不能访问馆主草稿。接通发布、链接交付、换链与停止分享。草稿修改不直接改变参观内容。
- 照片平面缺图可保存草稿，确认与发布在界面和服务端均阻止并明确提示补图；补图保存后仍须确认当前版本。WebGL 中断时返回按钮位于遮罩上方，归位不依赖上下文恢复；按需渲染闲置后重置时钟，连续低帧率仍按实际帧间隔归位。
- “照片生成 3D”显示“混元 · 尚未接入”且不可提交；单图与四视图照片准备已接入展品草稿，提交契约已有预留。没有虚构任务、生成结果、进度或服务配置，实际任务及候选采纳等待 C/D 交付。

此前四项评审修复复用既有会话机制，补齐参观路由鉴权和缺图校验；当时实现的登录后返回参观链接已被本轮明确决策替换。本轮将个人展馆流程、新增迁移与此前首页、登录页视觉一起交付上游 PR #9。复核仍为单人自查，尚需 A/C/E 按职责核对体验、数据接入与真实设备；本地自动化和截图不能替代独立验收。
