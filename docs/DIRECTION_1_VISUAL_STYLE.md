# 方向一界面样式约定

2026-10-24 用户明确要求：新增页面的色调、字体、页面与控件风格必须与整个系统一致。此前任务单的米白/灰绿要求已被替代。

## 现有系统是设计依据

- 首页与登录：`src/app/page.tsx`、`src/app/globals.css`、`src/features/studio/login-form.tsx`。
- 工作台：`src/features/studio/workbench.css`。
- 参观：`src/features/viewer/shared-museum.module.css`、`museum-visit.css`。
- 参考成熟开源方案 [Radix Colors](https://github.com/radix-ui/colors) 的主题组织思路；沿用本项目现有配色和 CSS，不安装新组件库，不复制第三方界面。

## 本轮采用的样式

| 元素 | 值与规则 |
| --- | --- |
| 页面底色 | `#100D0A`，沿用首页、登录 |
| 卡片、面板 | `#19140F`；输入底色 `#14100B` |
| 正文 | 暖米色 `#F0E8DA`；辅助文字 `#B7A994` |
| 主色与焦点 | 黄铜金 `#C8A56B` |
| 主按钮 | 首页同款 `#E1C58E` → `#C2A36B`，深棕文字 `#2B2014` |
| 边线 | 工作台同系 `#493C2D`，细边框 |
| 标题、阅读正文 | 现有 `--font-serif`，使用宋体类字体栈 |
| 表单与普通正文 | `Noto Sans SC`、`Microsoft YaHei`、系统无衬线 |
| 圆角与布局 | 输入 4px、面板/按钮 6px；沿用工作台的简洁细框；桌面网格、手机单列 |
| 状态 | 金色确认/选中；暖红错误和删除；文字同时说明含义 |
| 书籍 | 深棕红封面、金色细节；阅读弹窗使用同系深底与暖米文字 |

世界、自传、导览共同消费 `src/features/direction1/demo.module.css` 的 `--demo-*` 变量。嵌入展柜所需的 `--wb-*` 在同一作用域映射，避免按钮和说明因缺失变量变得不可读。不得把这些变量的修改写进全局首页或工作台。

## 另一位 agent 的执行边界

继续遵守 `DIRECTION_1_AGENT_HANDOFF.md` 的三文件白名单。本对话负责公共 DEMO 样式与书籍 CSS；另一位 agent 的新世界 CSS module 从现有页面继承 `--demo-*`，负责布局与局部状态。不要重新硬编码米白背景或灰绿主按钮，不修改公共 CSS、业务状态或权限。

如果独立目录中的样式文件还是旧版本，先获取本轮公共 CSS 的源码快照；只拉 HEAD 无法取得尚未提交的文件。本轮不改变功能范围，也不要求重做首页、登录、工作台和三维展柜。
