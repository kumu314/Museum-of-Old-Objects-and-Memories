## 1. 三个直接改变打法的发现

**① 单图 → 3D 已经降到"秒级 + 开源"，但有质量天花板。**
Apple SHARP（论文 2025-12-11，已开源，Docker 可用）：单张照片前馈预测 3D 高斯参数，标准 GPU 上**不到 1 秒**，随后 100+ FPS 实时渲染。TripoSR（Stability AI 与 VAST，2024-03 开源）：单图 → 带贴图网格，A100 上约 0.5 秒，**无 GPU 也能跑**，但公开评测称其为"草图质量"。⇒ "用户拍张旧物照片就变 3D"在技术上已成立，但**旧物常见反光/透明/无纹理主体，两类模型都会明显退化**（此为推断，未实测，PRD 验证时第一件该测的就是拿真实旧物照片跑一遍）。

**② "AI 数字永生"赛道有两个公开的死亡案例，是我们的前车之鉴。**
HereAfter AI（AI 采访者 + 可对话记忆，199.99 美元一次性买断）**2026 年 7 月关停**，用户被要求发邮件取回录音；StoryFile（互动视频数字形象，累计融资约 950 万美元）**2024 年申请破产保护**。⇒ 做"缅怀逝者"方向的产品，商业上被反复证伪；做"家庭旧物纪念"（当事人活着、家庭共建、实物入口）风险结构完全不同——这是我们选题结构性占优的地方，路演可以主动讲。

**③ 国内"数字纪念馆"全是 2D 图文列表，3D 空间体验是空的。**
天堂网（2006 年至今）、云上思念、GetMemorial 等：建馆→传照片→写生平→留言祭奠，没有空间感、没有策展叙事。B2B 虚拟展厅（Ai3D、云展云、视创云展）有 3D 但面向企业营销、模板化、按项目收费。⇒ "个人/家庭的 3D 纪念展柜"在国内外都找不到对标产品，这是创意分的支撑点（清理前评分分析 §3.3 的主观估分依据，不能视为评委实际评分）。

## 2. 技术实现路线（按 30 小时赛期倒排，含代价）

### 2.1 展柜本体：三条路线

| 路线 | 做法 | 工时量级 | 效果 | 主要风险 | 什么时候别用 |
|---|---|---|---|---|---|
| **A. Three.js 可漫游展厅** | 参考 gallery 项目（three.js + Blender 烘焙场景 → GLB，WASD 行走 + 射线交互 + 位置音频） | 8–16h（含建模） | 沉浸感最强，"走进博物馆" | Blender 建模吃时间；移动端适配 | 没人会 Blender 或时间 <20h |
| **B. model-viewer 单展品矩阵** | Google Web Component，GLB/glTF，自带轨道控制/自动旋转/阴影/Draco 解压/AR | 2–4h | 干净但单展品感，拼不成"展柜" | 多展品布局要自己搭 DOM | 想要空间叙事时 |
| **C. 3DGS 实景还原** | SHARP/Forge 把真实空间变 3D 高斯 | 4–8h | 照片级真实 | GPU 要求、场景编辑能力弱、许可未核 | 无独显 GPU 时 |

**混合方案（本文倾向，供 PRD 参考）**：B 打底（2–4h 出可演示闭环），把"展柜"用 DOM+CSS 3D 变换搭成分格展台，每个格子嵌一个 model-viewer 或带照框的展品卡；若时间富余再上 A 的漫游。理由：完成度占总分 33/100（分母取法：百分制总分 100；分子 = 人类评委侧 21 + AI 评委侧 12，即人类侧完成度 30 分×0.7、AI 侧 40 分×0.3 计入，完整推导见 [历史评分推导](https://github.com/kumu314/Museum-of-Old-Objects-and-Memories/blob/f11a50c02308397effedc7202a6808a4417ee679/docs/06-%E8%AF%84%E5%88%86%E5%87%86%E5%88%99%E4%B8%8E%E9%87%8D%E6%8E%92.md)）且"打开就能用、换个输入也能跑"是硬标准，先保能跑。

### 2.2 旧物 → 3D：四条路

| 路线 | 输入 | 速度/质量 | 适用 |
|---|---|---|---|
| Meshroom（AliceVision 系，开源摄影测量） | 多张重叠照片 | 小时级，质量最高 | 赛前预建模精品展品 |
| **TripoSR**（开源，2024-03） | 单图 | ~0.5s（A100），无 GPU 可跑，草图质量 | 现场演示"换输入也能跑" |
| **Apple SHARP**（开源，2025-12） | 单图 | <1s（标准 GPU），3DGS 表示，100+ FPS 渲染 | 同上，效果更好但吃 GPU |
| 手机 App（Polycam/Scaniverse/3D Scanner App） | 照片或 LiDAR | 分钟级，质量好，人工兜底 | 赛前人工扫描几个真实旧物 |

**演示策略建议（关键）**：现场链路 = 用户照片 →（AI 修复）→ 3D 重建 → 上架展柜。真实旧物建模质量不可控，所以**赛前预扫描/预建模 3–5 件精品**保证演示效果，现场换输入时跑通链路即可（管线通≠每件都完美，这正是"换个输入也能跑"的诚实演示）。

### 2.3 AI 整理故事

- **老照片修复**：GFPGAN/ComfyUI 开源链（RestorePhotos.io 即基于 GFPGAN）、即梦 AI、MyHeritage Deep Nostalgia（会动的老照片）。注意科普中国文章提示的伦理：**修复/上色是"解释"不是"还原"，要保留原图**。
- **口述 → 结构化展品故事**：LLM（免费渠道：WorkBuddy 中国版 Step / DeepSeek V4.1 Flash，**渠道存在≠项目可接入，key 未确认**）。把"这杯子是爷爷 80 年代跑运输买的"这类口述整理成时间线、人物标签、展品说明。
- 多藏品语义检索（RAG）是自然延伸，本次未调研框架选型。

### 2.4 交付形态

纯静态 Web（GitHub Pages 类）最稳：无服务器依赖、AI 评委直接可看。**必须配录屏**——评分准则原文："演示现场出问题，允许重试一次；还不行，按提交的作品和录屏打分"。

## 3. 设计灵感（三个可偷师的）

1. **Museum in a Box**（museuminabox.org）：实物贴 NFC 贴纸，放到盒子上就播放它的故事。"实物即界面"——我们不做硬件，但"每件旧物是一个可触发的故事单元"这个信息架构可以直接搬上网页。
2. **Google Arts & Culture / Sketchfab museums**：超高分辨率图像 + 策展叙事 + 360° 漫游。学它的"一件展品配一段故事"的叙事节奏，别学它的重资源。
3. **反面教材：天堂网式 2D 纪念馆**。列表、相册、留言板——功能全但没有"想去看看"的瞬间。我们的展柜要做的就是这个瞬间。

## 8. 对本赛题的落地建议（输入给 PRD，不是决定）

**建议的最小闭环**（按历史评分分析的权重倒推：完成度占总分 33/100——分母取法：百分制总分 100，分子为人类侧 21/100 加 AI 侧 12/100，即人类评委百分制中完成度占 30 分、按 0.7 计入总分，AI 评分百分制中占 40 分、按 0.3 计入，完整推导见 [历史评分推导](https://github.com/kumu314/Museum-of-Old-Objects-and-Memories/blob/f11a50c02308397effedc7202a6808a4417ee679/docs/06-%E8%AF%84%E5%88%86%E5%87%86%E5%88%99%E4%B8%8E%E9%87%8D%E6%8E%92.md)——是唯一必须死守项）：

1. 上传旧物照片（换一张也能跑）→ AI 修复 → 生成展品
2. 3D 展柜：分格、灯光、可旋转检视；点开展品看故事
3. 口述/文字 → LLM 整理成展品故事与时间线
4. 打包：可运行 Web + 录屏 + README

**前提（未验证的）**：TripoSR/SHARP 对真实旧物的重建质量可接受（第一件该测的事）；免费模型的 key 拿得到。
**代价**：路线 B 打底会牺牲部分沉浸感；若上 Three.js 漫游，时间风险集中在建模。
**失效边界**：如果真实旧物重建效果不可用，退路是"展品卡 = 修复照片 + 3D 展柜空间"，3D 只做展柜不做展品——闭环仍然成立。
**OPC 叙事配合**：材料里把产品讲成"一个人 + AI 就能经营的纪念展制服务"（OPC 赛道考察个人经营公司综合能力，[赛事方向记录](https://github.com/kumu314/Museum-of-Old-Objects-and-Memories/blob/f11a50c02308397effedc7202a6808a4417ee679/docs/06-%E8%AF%84%E5%88%86%E5%87%86%E5%88%99%E4%B8%8E%E9%87%8D%E6%8E%92.md)），技术栈细节放附录。

**不按这个闭环做的基线**：若只做"上传→修复→2D 相册"（砍掉展柜），完成度链路仍在、能跑，但形态退化成天堂网式 2D 纪念馆，创意与场景两项失去支撑；若等 PRD 全部想清再动手，10 月 24 日上场时没有可运行作品 = 完成度 0–2 分（[历史选题分析](https://github.com/kumu314/Museum-of-Old-Objects-and-Memories/blob/f11a50c02308397effedc7202a6808a4417ee679/docs/06-%E8%AF%84%E5%88%86%E5%87%86%E5%88%99%E4%B8%8E%E9%87%8D%E6%8E%92.md)）。展柜与"修复+整理"链路解耦，展柜做砸了相册仍在，这是允许的部分失败。
