## 1. 什么时候跑哪些行

| 触发条件（§10.1） | 跑哪些行 |
|---|---|
| 改局部逻辑、页面或样式 | 只跑受影响的不变量与关联流程，按「关联」列挑行，不默认跑全表 |
| 工程初始化 | 建立类型检查、lint、业务测试、生产构建的实际入口，并落实 CI 检查 |
| 首次完整上线，或影响多个核心流程的变更 | 全表适用行 + 桌面一台 + 实际手机一台 |
| 实际部署 | A20 至 A23（生产构建、原生依赖、重启后数据与素材仍可读） |

未选择的制作模式、未纳入首版的可选功能不进入本次验收。

## 6. 本清单当前的已知缺口

1. **一条都还没跑**——仓库尚无产品代码，全部状态为「未实现」。
2. **A01 的「重启服务」依赖数据库形态**——v0.6 已把数据基线定为 PostgreSQL，重启验证要连同 PostgreSQL 的持久化一起做，不能只重启 Node 应用。
3. **手机型号未定**——DEV-2 无法指定具体机型。
4. **部署环境未定**——A01 在哪个环境跑，取决于 C 的 G0 与部署方案。
5. **未覆盖的边界**——动态图片的具体格式清单、非允许音频编码的具体清单，依赖 D 的校验实现，实现前无法枚举。
6. **v0.6 §10.2 仍是"未来实现的验收要求，尚无运行结果"**——本清单的 27 条全部照抄自该节，不构成任何已完成证据。
