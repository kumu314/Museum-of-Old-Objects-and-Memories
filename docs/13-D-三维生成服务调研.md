# D：照片生成 3D 服务调研（未选型）

更新：2026-10-24

本页记录候选服务的官方资料核对结果，不表示任何服务已可调用、已购买额度或已通过生成验收。当前文字 AI 使用 DeepSeek，与三维生成无关，不能作为照片建模成功证据。

## 结论先行

1. **本轮不选型、不接入、不付费试跑。** 需要 A 先确认产品取舍，C 确认任务/存储/部署代价，并取得账号、额度和素材外传授权。
2. **第一候选：Tripo**。官方价格页可核实图生 3D 20/30 credits（1 credit = $0.01），成本较低；但官方 API 文档在本次抓取中为客户端渲染空页，提交/查询、异步任务、GLB 下载和 URL 有效期必须登录官方文档/账号核实后才能定为可用。
3. **备选：Meshy**。官方 API 文档最完整：图像 URL/base64、异步任务、GLB、`auto_size` 与 `origin_at: bottom` 都有明确说明；但要求付费计划，`auto_size` 只是 AI 估算高度，不能当真实物理尺寸。
4. **国内支付/访问备选：腾讯混元 3D**。官方价格页确认图生 3D、100 免费积分、失败不扣积分，价格 0.1–0.12 元/积分；GLB 输出、提交/查询接口和 TokenHub 迁移需在官方控制台/API 文档核实。不要把“图生 3D”直接等同于“GLB API 已验证”。

## 对实现边界的直接影响

- **不能先写某家的适配器再选型。** 当前仓库只有文字 AI 适配器和内置模型清单，没有三维提交/查询/下载模块。选型后再按官方契约实现最小适配器。
- **任务所有权归 C。** D 的适配器返回外部 task id、状态、结果和失败类别；C 负责用户、输入素材、来源版本、任务持久化、去重、恢复、用量和付费边界。D 不另建任务数据库或“提交成功”假状态。
- **付费提交结果不明时先查询，不自动重提。** 外部任务创建是可能计费的非幂等操作；没有确认结果前不能盲目重试。
- **结果必须立即下载并转为私有资产。** 供应商签名 URL 会过期；不能把临时 URL 作为永久分享地址。生成结果按不可信外部资产完整解析、校验资源预算和外部引用后再入库。
- **Draco 不由供应商默认值决定。** 当前展示端没有 `DRACOLoader`。实际下载的 GLB 若有 Draco，必须先确认转换/解码方案；不能把压缩比例当作固定保证。若启用，作为 A/D/C 联动变更重新验收。
- **尺度不能依赖 `auto_size`。** 它是对照片的估算，不证明真实尺寸。D 在有用户测量或可靠参照时标定米制尺寸；没有依据时标记估算/未知，A 只负责陈列 scale。不得悄悄把最长边归一为 1 米。
- **朝向和原点由 D 在入库前规范化。** 交付按开发书 §9.6：右手系、Y 向上、正面 +Z、底部中心为原点、贴图内嵌。供应商的 `origin_at` 只能作为输入线索，不能代替对实际 GLB 的规范化验证。

## 选定后的最小试跑门槛

候选服务要进入实现，至少同时满足：

1. 官方 API 账号可用，明确额度、计费、并发、失败收费和数据处理条款。
2. 用获准使用的测试照片完成一次真实提交 → 查询 → 下载 GLB；记录耗时、扣费、失败情况和输出文件。
3. 验证实际 GLB 能否被现有 Three.js 加载链读取；确认是否 Draco、是否内嵌贴图、是否有外部 URL、坐标/原点/尺度是否异常。
4. 与 A 在目标电脑和实际手机上验证入柜、检视、快速切换、失败入口；与 A/C 实测后冻结文件、面数、纹理和解析预算。
5. 用户照片外传前完成用途告知与授权；真实用户素材不得用于未经许可的服务测试。

未完成以上步骤前，不把“服务存在”“网页效果不错”“供应商说支持 GLB”写成产品已具备照片生成 3D 能力。

## 下一步建议

先由 A 在 Tripo 与 Meshy 中确认优先服务：若成本优先且能取得 Tripo API 文档/账号，先试 Tripo；若希望文档完整、可先做接口验证，试 Meshy；若必须国内支付/访问，再核实腾讯混元的 API 与 GLB 输出。选定后由 C 给出任务表、权限、存储和部署方案，D 再实现适配器。
