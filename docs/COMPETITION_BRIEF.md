## 2. 评分与来源说明

原记录列出的四个维度为完成度与可用性、创意、场景价值、展示；人类评审占 70%，AI 评审占 30%。AI 子维度公式在原记录中有不同表述，A、E 需核对正式准则，本页不将历史分析算出的权重当作官方条文。

- 完成度需要能实际运行，换一组合理输入仍能完成流程。
- 场景价值需要说明具体用户、需求与已获得的反馈，不把主观估分当成实测结果。
- AI 评审依赖提交的作品与材料，README、截图、录屏和复现说明应能独立说明成果。
- 使用开源、模板或已有项目时说明来源，清楚区分本次新增成果；原记录称评审只评价比赛期间新增部分，适用边界由 A、E 向主办方核对。
- 原记录称现场故障允许重试一次，仍失败时按已提交作品和录屏评分；演示前准备可用的备用入口。

## 3. 提交前由 A、E 核对

- 正式提交入口、硬截止、路演时间地点与材料格式。
- 报名与团队信息是否正确，已有项目和赛前准备内容如何披露。
- 实际演示地址、另一浏览器访问与录屏是否可用，私有素材和凭据是否已排除。
- 模型与第三方素材的来源、许可和实际用途；模型免费渠道不代表项目已经取得 API 额度或调用权限。

本页只记录赛事背景，不定义产品范围。2026年10月24日用户已将最终成品调整为方案 B 加照片生成 3D 模型，具体范围与验收以开发书 v0.7 为准；照片修复、大型漫游及其他未选方向不因赛事材料自动进入实现范围。
