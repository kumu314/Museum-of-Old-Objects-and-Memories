更新：2026-10-24。应用、三维原型、测试与文档使用根目录统一工程和锁文件。最终目标已改为方案 B 加自动建模；用户身份与归属已有实现，本分支新增工作台及正式参观页，照片生成 3D 仍未接入，本页命令描述当前实际可运行内容。

## 工具链与配置

固定 Node.js **26.12.0**、pnpm **12.14.0**、PostgreSQL **18.6**。直接依赖精确版本见 `package.json`，完整依赖树见 `pnpm-lock.yaml`；三维预览使用同一工程内的 Vite。音频校验需要系统 `ffmpeg` / `ffprobe`，CI 已安装。

```sh
pnpm install --frozen-lockfile
pnpm db:local
pnpm db:migrate
pnpm db:migrate:test
pnpm dev
# 另一个终端启动独立三维原型
pnpm dev:scene
```

`db:local` 需要 Docker Compose，创建开发与测试两个 PostgreSQL 容器及各自持久卷，端口为 15432 / 15433。保留已有 `.env.local`；首次运行生成私密配置与 `.local/uploads`。应用账号无超级用户、创建库或创建角色权限，两个容器使用不同凭据。不要使用 `docker compose down -v` 删除数据。

应用地址为 `http://127.0.0.1:17682/`，三维原型为 `http://127.0.0.1:17681/`。启动前检查端口占用。`/api/health` 校验数据库迁移记录及上传目录可读写。

外置 PostgreSQL 时，依据 `.env.example` 创建 `.env.local`，不覆盖已有配置。`DATABASE_URL` 与 `TEST_DATABASE_URL` 必须指向隔离数据库；`UPLOAD_DIR` 为 `public` 之外、应用账号可读写的绝对路径；`SESSION_PASSWORD` 至少 32 个随机字符。真实配置、凭据、数据库和素材均不得进入 Git。

停止本地数据库但保留数据：

```sh
docker compose -f compose.local.yml stop
```

## 用户注册与登录

没有客户自助注册以外的账号开通入口；`team:create` 脚本已随方案 B 移除，旧团队账号经迁移 `0003` 演化为普通用户账号，已建展馆归属到创建者名下。

用户在 `/login` 页面注册或登录：用户名 2–40 个字符（文字、数字、下划线或连字符），密码至少 8 位；注册即登录并进入个人工作台。展馆只能被创建者访问，其他用户访问返回 404。登录与注册共用 iron-session 加密 cookie 与数据库会话记录，8 小时过期，退出后会话撤销；写请求校验 Origin，生产 cookie 只经 HTTPS 发送。每用户名五分钟最多十次登录或注册尝试。账号恢复（忘记密码）尚未实现，接入方式见开发书第 9.4 节，待选定认证方式后补充。

## 收录、确认与参观

登录后从 `/studio` 进入自己的展馆。在工作台选择空格，填写旧物名称和共同回忆，上传照片并说明来源；展签可人工填写，也可在保存讲述后使用“整理故事”。保存时沿用完整字段校验，尚不支持只含名称和回忆的不完整草稿持久化。

桌面按素材、故事、确认三栏排列；窄屏切换同名页签，输入保持不变。单击柜格切换编辑对象，“检视模型”在当前页放大；Esc 或返回按钮放回展柜。照片平面展示与内置演示模型均标明来源，当前“生成 3D 模型”不可用，不能视为真实建模流程已完成。

保存不等于确认。核对展签、展示方式和素材后填写私有确认记录，明确确认当前版本；所有旧物确认后，发布生成不可变快照并交付 `/share/[token]` 链接。原始讲述、内部草稿和确认记录不进入公开数据。发布后继续编辑须重新保存、确认和发布，原快照保持不变。

参观链接仅在创建或更换时交付，不保存完整 token 到浏览器持久存储；刷新工作台后，已有链接仍可用，未保留链接时可明确更换。更换链接或停止分享会使旧链接的数据及私有素材新请求失效，无法撤回已下载的副本。参观页只读公开快照，在模型或 WebGL 故障时仍提供故事、实拍及原声。

## 检查与 HTTP 回归

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm test:db
pnpm test:scene
pnpm test:http
pnpm build:scene
APP_ORIGIN=https://museum.example.test pnpm build
# 仓库规范与应用检查；HTTP 回归在 CI 中另列一步
APP_ORIGIN=https://museum.example.test bash scripts/check.sh
```

- `test`：契约、配置、素材处理与 AI 适配边界。
- `test:db`：使用 `TEST_DATABASE_URL` 的实际 PostgreSQL，检查迁移、约束、事务、快照、撤销与 AI 来源版本。
- `test:scene`：独立场景的纯逻辑测试，不能替代浏览器视觉验收。
- `test:http`：执行 `tests/e2e/api-core.test.ts` 与 `assets-http.test.ts`。需先运行 `pnpm db:local`；仅使用本项目 15433 端口的 Compose 测试容器，在容器内创建本次专用临时数据库，运行迁移并创建随机密码的测试账号。应用源码副本、Next 开发缓存与上传文件放在私有 `.local/http-regression-*`，独立进程使用自动分配的回环端口。结束时停止该进程并移除本次数据库和临时文件，保留 `server.log` 供诊断；不清空开发库、常规测试库或原上传目录，不连接真实 AI。

CI 运行冻结锁安装、实际 PostgreSQL 迁移、类型检查、lint、契约/服务端/实库/场景测试、两种生产构建和 HTTP 回归。HTTP 回归验证实际路由、会话与文件读写，但使用 Next 开发服务器，不替代生产部署或完整浏览器端到端验收。
