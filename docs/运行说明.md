## 单一工具链与入口

沿用已有业务原型的 Node.js 26.12.0、pnpm 12.14.0、PostgreSQL 18.6；Next.js 16.4.3、React 19.3.1、Three.js 0.186.1、TypeScript 6.0.3。所有直接依赖精确固定在 `package.json`，包括原主仓库需要的 music-metadata 11.16.1。三维预览使用 Vite 8.3.5，同样纳入主锁文件。

```sh
pnpm install --frozen-lockfile
pnpm db:local
pnpm db:migrate
pnpm db:migrate:test
pnpm dev
# 在另一个终端启动同仓库三维原型
pnpm dev:scene
```

应用地址 `http://127.0.0.1:17682/`，三维预览地址 `http://127.0.0.1:17681/`。数据库端口仍为 15432 / 15433，沿用 `compose.local.yml` 的原有项目名和持久卷，避免误建空库。不要运行 `down -v`。保留的 `.env.local` 只调整 `UPLOAD_DIR` 到统一目录，账号、数据库、会话密钥保持原值。私有文件均被 Git 忽略。

SQL 入口统一为 `scripts/migrate.ts` 与 `src/server/db/migrate.ts`，配置统一为 `src/server/config.ts`。保留已应用的业务迁移原文，测试使用隔离数据库和临时 schema。原主仓库的配置与迁移回归场景已迁入 Node 测试入口，不再维护另一套 Vitest 或 PostgreSQL 17 配置。

浏览器实际验证三件模型加载、目录选择、取出和 Esc 放回；应用健康接口返回数据库/存储均 ok，未登录的制作 API 返回 401；原浏览器会话仍能进入工作台并读取已有演示展馆。Vite 提示场景主包大于 500 kB，这是现有 Three 场景体积提示，本次没有放宽告警门槛。

本机预览由用户级临时服务运行，工作目录均为 `heikesong`。应用服务 `codex-heikesong-app-preview.service`（17682），场景服务 `codex-heikesong-scene-preview.service`（17681）；可用以下命令停止，再按上面的 pnpm 命令手动启动：
