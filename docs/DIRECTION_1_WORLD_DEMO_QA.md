## 界面改动摘要

- **页面层次**：演示导航（DEMO 导览 / 自传 DEMO / 我的工作台）与 DEMO 合成资料横幅保持原样；目录区改为 `region` + 标题关联（`aria-labelledby`），筛选按钮组加 `role="group" aria-label="目录筛选"`；卡片标题从 `h2` 降为 `h3`，层级为 页面 h1 → 分区 h2 → 卡片 h3。
- **搜索/筛选与卡片**：保留四字段搜索标签与占位符、`全部公开馆`/`我的关注列表`（`aria-pressed`）；卡片重排为 作者眉题 → 馆名 → 简介 → 标签 → 展品 → 收藏总数（"收藏者身份不展示"文案保留）；自己的馆显示"我的展馆"徽标而不是隐藏按钮；关注/收藏按钮增加 `aria-pressed` 表达当前状态，可见名称不变。
- **空态**：无结果时保留原提示文案，新增 `清除搜索` 按钮（有搜索词时）与 `查看全部公开馆`（关注列表视图为空时），按钮即可返回完整目录。
- **选中馆与返回入口**：点击 `参观 {馆名}` 后自动滚动到参观区（`prefers-reduced-motion: reduce` 时直接定位不平滑滚动）；新增粘性参观条显示 `参观中` 徽标、馆名、作者，并提供 `返回展馆目录` 锚点链接与 `退出参观` 按钮；被选中卡片加描边、底色与 `参观中` 徽标及 `aria-current="true"`。
- **留言簿**：根留言与回复改为嵌套有序列表（`ol > li`，回复带左侧竖线缩进）；每条留言为作者行 + 正文 + 操作行；馆主视图中被禁评作者显示 `已禁评` 徽标；隐藏/删除正文的管理态样式区分（隐藏正文暖红底、删除正文斜体占位）；回复时保留 `正在回复 {昵称}` 与 `取消回复`；留言簿相关操作的失败信息就近显示在表单上方（`role="alert"`），其余失败仍在页顶。
- **关闭/禁评提示**：本馆关闭留言或当前虚构身份被禁评时，表单上方显示明确说明（"本馆已关闭新增留言，作者仍可删除自己的留言。" / "当前虚构身份在本馆被禁评，仍可参观。"），输入框与提交按钮禁用。规则判定仍完全来自 `demo.ts` 的状态，界面只做展示，未复制权限逻辑。
- **样式边界**：新样式全部在 `world-demo.module.css`（米白 #f5f1e9 / 木色 #6b5a3f·#b37d28 / 灰绿 #425c45·#5f6e58），继续复用公共 `demo.module.css` 的外壳、面板、按钮、输入与状态样式；公共文件未改。卡片网格 `auto-fill minmax(280px,1fr)`，窄屏自然单列；按钮最小高度 44px；卡片与留言文本 `overflow-wrap:anywhere` 防长文溢出。
